# Mo IPTV Checker — فاحص سيرفرات IPTV

أداة محلية لفحص سيرفرات
IPTV
(Xtream / Stalker-MAC / M3U).

## الجديد في الإصدار 6.0
- حفظ تلقائي للجلسة واستعادتها عند الفتح، ومجلد بيانات خاص بكل مستخدم.
- فلتر لكل عمود في صف العناوين (مثل إكسل)، وفلتر تلقائي في ملف الإكسل المُصدَّر.
- فحص بث فعلي (عميق) بجودة البث، وتقييم من 100، ونافذة تفاصيل، وسجل الفحوص.
- تحديد متعدد وإجراءات جماعية، تراجع عن الحذف، إضافة سيرفر يدوياً، وسوم وملاحظات، إخفاء الأعمدة.
- مشغّل لكل الأنواع (Xtream / Stalker / M3U) مع EPG ومفضلة وسجل مشاهدة واستئناف وتحويل عبر ffmpeg.
- صفحة إعدادات، سجل تشخيص، وتنبيه عند توفر إصدار جديد.
- عند وسم إصدار جديد `v*` تُنشر ملفات التثبيت تلقائياً في صفحة Releases.

## تنزيل التطبيق الجاهز (بدون تثبيت Python)
افتح تبويب **Actions** بالأعلى، اختر آخر تشغيل ناجح، وانزل إلى قسم **Artifacts**:

- `Mo_IPTV_Checker-windows` — يحتوي على:
  - `Mo IPTV Checker Setup.exe` — ملف تثبيت كامل لويندوز (ثبّت ثم شغّل من قائمة ابدأ)
  - `Mo IPTV Checker-windows.exe` — نسخة محمولة تعمل مباشرة بدون تثبيت
- `Mo_IPTV_Checker-macos` — يحتوي على:
  - `Mo IPTV Checker.dmg` — ملف تثبيت لماك (افتحه واسحب التطبيق إلى Applications)
  - `Mo IPTV Checker-macos.zip` — نسخة التطبيق المضغوطة
- `Mo_IPTV_Checker-linux` — برنامج لينكس

على ماك أول مرة: زر يمين على التطبيق ثم
Open
(لتجاوز تحذير
Gatekeeper
لأن التطبيق غير موقّع).

## التشغيل من المصدر
```
python iptv_checker.py
```
تفتح الواجهة في المتصفح تلقائياً.
