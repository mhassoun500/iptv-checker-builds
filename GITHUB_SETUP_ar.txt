بناء نسخ IPTV Checker المستقلة تلقائياً عبر GitHub
====================================================
النتيجة: برنامج جاهز لويندوز (.exe) وماك ولينكس، تنزّله جاهزاً بدون تثبيت Python.

الخطوات (مرة واحدة، نحو 5 دقائق):

1) انشئ حساباً مجانياً على github.com اذا لم يكن لديك.

2) انشئ مستودعاً جديداً:
   - اضغط زر + بالاعلى يميناً ثم  New repository
   - الاسم مثلاً:  iptv-checker-builds
   - اختر Public (او Private لك وحدك) ثم  Create repository

3) ارفع ملفات البرنامج:
   - في صفحة المستودع اضغط  Add file  ثم  Upload files
   - اسحب الملفين:  iptv_checker.py   و   app.ico
   - اضغط  Commit changes

4) اضف ملف البناء (مهم جداً):
   - اضغط  Add file  ثم  Create new file
   - في خانة اسم الملف اكتب بالضبط:
         .github/workflows/build.yml
     (الشرطة المائلة / تنشئ المجلدات تلقائياً)
   - الصق محتوى الملف build.yml الموجود في هذه الحزمة بالكامل
   - اضغط  Commit changes

5) يبدأ البناء تلقائياً:
   - افتح تبويب  Actions  في اعلى المستودع
   - انتظر حتى تكتمل المهمة (علامة صح خضراء) — نحو 3 الى 5 دقائق
   - اضغط على المهمة، وانزل للاسفل الى قسم  Artifacts
   - حمّل:
        IPTV_Checker-windows   (بداخله IPTV_Checker-windows.exe)
        IPTV_Checker-macos     (بداخله IPTV_Checker-macos)
        IPTV_Checker-linux

ملاحظات:
- الملف الذي تنزّله مضغوط من GitHub؛ فك الضغط ثم شغّل البرنامج بالنقر المزدوج.
- ماك: اول تشغيل قد يمنعه النظام — زر يمين ثم Open مرة واحدة.
- لاعادة البناء بعد اي تعديل: ارفع iptv_checker.py الجديد، فيبني تلقائياً.
- تحميل ملفات Actions يتطلب تسجيل الدخول بحسابك (وهو حسابك فلا مشكلة).
